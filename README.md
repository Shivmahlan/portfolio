# Shiv's Data Ledger — Portfolio

Personal portfolio for Shiv Kumar (Shivmahlan): data-science student, ML / computer-vision builder.

Built with Vite + React 19 + GSAP.

## Develop
```bash
npm install
npm run dev      # http://localhost:5173
```

## Build
```bash
npm run build    # outputs to dist/
npm run preview  # preview the production build
```

## Deploy
Static SPA. Set the framework preset to **Vite** (Vercel / Cloudflare Pages):
- Build command: `npm run build`
- Output directory: `dist`

No server or API keys required — profile data is pulled client-side at runtime.
